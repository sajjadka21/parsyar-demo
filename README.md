# ParsYar Demo

A standalone, Persian-first preview of ParsYar's gym-management dashboard. The interface uses fictional sample data and does not connect to the production app, database, SMS provider, or any account.

**Live product:** [parsyar.hivenest.ir](https://parsyar.hivenest.ir)

## Preview

Open `index.html` in a browser. The demo uses plain HTML, CSS, and JavaScript with no build step or third-party dependencies.

## What is included

- Right-to-left Persian dashboard layout
- Responsive desktop and mobile presentation
- Fictional membership, attendance, and finance summaries
- Lightweight sample interactions for navigation and notices
- Direct link to the live ParsYar site

## Privacy and scope

This is a UI showcase only. It contains no production source, customer records, credentials, API keys, or backend connection. Names, membership details, totals, and dates shown in the preview are invented for demonstration.

The product itself remains in its separate private repository. This demo does not provide login or operational gym-management features.
